<h3 align="center">Pengembangan Sistem Informasi Booking dan Manajemen Layanan Pada Studio Nail Art Berbasis Web.</h3>
<p>Aplikasi Sistem Informasi Booking dan Manajemen Layanan Nail Art Berbasis Web merupakan platform digital yang dirancang untuk membantu Alia Oye Studio dalam mengelola proses pemesanan layanan secara terstruktur dan terintegrasi. Sistem ini memungkinkan pelanggan untuk melihat katalog layanan, melakukan booking berdasarkan jadwal, mengunggah bukti pembayaran, serta memantau status pesanan. Sementara itu, admin dapat mengelola layanan, jadwal, transaksi, dan data pelanggan dalam satu sistem terpusat. Dengan adanya aplikasi ini, proses operasional menjadi lebih efisien, mengurangi kesalahan pencatatan, serta meningkatkan kualitas pelayanan kepada pelanggan.</p>
